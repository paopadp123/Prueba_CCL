# Prueba CCL - Sistema de Gestión de Inventario

Aplicación web para registrar entradas y salidas de productos y consultar el inventario actual.

## Stack

- **Backend:** C# / .NET 10, ASP.NET Core Web API, Dapper
- **Base de datos:** PostgreSQL 17 con stored procedures
- **Frontend:** Angular 20
- **Autenticación:** JWT
